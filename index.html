A course in 11 layers

Motion from Scratch

How to go from pixels to motion. Start with one pixel, add one idea per layer, and finish by rebuilding a real motion-graphics intro and exporting it as an MP4. No libraries, no install.

  10  Export          frames → MP4, then map it all to Remotion
  09  KineticIntro    the recreation
  08  Scenes          sequences, camera, masks, seeded randomness
  07  Canvas          transforms + blur by hand, then real fonts
  06  Springs         physics stepping and stability
  05  Easing          a cubic-Bézier solver
  04  Interpolate     lerp, clamp, ranges, extrapolation
  03  Time            frame = f(n), a player that keeps time
  02  Glyphs          text from a hand-made bitmap font
  01  Shapes          rectangles, circles, alpha, gradients
  00  Pixels          a framebuffer: memory you can see
      ▲ each layer is built only from the layers below it

Then, for every layer

  1. Read the chapter. It explains what's happening underneath, with diagrams.
  2. Predict: each prediction block has a line for your guess. Fill it in, press Run, and it tells you whether you were right.
  3. Write the functions. Each comment in the starter code is the spec; each body says "not written yet" until you replace it.
  4. Check with the tests. A failing test tells you the exact value it expected and what it got. Pictures appear as your code starts working.
  5. Break it: each experiment has a TODO saying what to change in your code. Run it before and after the change, explain the difference, then undo it.
  6. Move on when every test passes and you can answer the checkpoint questions without looking.

You've finished the course when layer 10 exports your own KineticIntro as an MP4.
