Then, for every layer

  1. Read the chapter. It explains what's happening underneath, with diagrams.
  2. Predict: each prediction block has a line for your guess. Fill it in, press Run, and it tells you whether you were right.
  3. Write the functions. Each comment in the starter code is the spec; each body says "not written yet" until you replace it.
  4. Check with the tests. A failing test tells you the exact value it expected and what it got. Pictures appear as your code starts working.
  5. Break it: each experiment has a TODO saying what to change in your code. Run it before and after the change, explain the difference, then undo it.
  6. Pass the checkpoint. When every test passes, the checkpoint unlocks: your code draws a mystery picture full of the chapter's traps, and you answer three questions. Both right means the layer is ★ complete.

You've finished the course when layer 10 exports your own KineticIntro as an MP4.

Using Claude in Chrome? Set up /tutor

The Claude in Chrome extension can read the guide and look at your pictures with you, so you don't have to paste anything. It needs a paid Claude plan.

  1. Copy the text below.
  2. In Claude's side panel, save it as a shortcut named tutor. Type / in the chat to find shortcuts.
  3. On the guide, type /tutor. Claude reads the layer's What your tutor sees panel: your code, your test results and the hint level you've chosen with Hint please.

The rules live in your own shortcut on purpose: Claude in Chrome treats text on a web page as information, not as instructions, so a page can't tell it how to behave.

Using Claude Code? Download the code, then open the folder in the Claude desktop app's Code tab, or run claude inside it. It reads CLAUDE.md on its own and can run the tests to see where you are. Codex reads AGENTS.md the same way.
