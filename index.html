A course in 11 layers

Motion from Scratch

How to go from pixels to motion. Start with one pixel, add one idea per layer, and finish by rebuilding a real motion-graphics intro and exporting it as an MP4. No libraries, no install.

  10  Export          frames → MP4, then map it all to Remotion
  09  KineticIntro    the recreation
  08  Scenes          sequences, camera, masks, seeded randomness
  07  Canvas          transforms + blur by hand, then real fonts
  06  Springs         physics stepping and stability
  05  Easing          a cubic-Bézier solver
  04  Interpolate     lerp, clamp, ranges, extrapolation
  03  Time            frame = f(n), a player that keeps time
  02  Glyphs          text from a hand-made bitmap font
  01  Shapes          rectangles, circles, alpha, gradients
  00  Pixels          a framebuffer: memory you can see
      ▲ each layer is built only from the layers below it

How it works

  1. Read the layer's chapter in docs/ (or the interactive guide).
  2. Write the functions in src/. Each comment is the spec, and each body starts as a placeholder that says "not written yet".
  3. Check by opening tests.html or running node tests/run.js. Pictures appear as your code starts working.
  4. Get unstuck with an AI study buddy. Open this folder in Claude Code or Codex; CLAUDE.md and AGENTS.md make it ask questions and give hints, never answers.
